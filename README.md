## About

PrimeTV is a modern streaming interface for discovering movies and TV shows, searching titles, viewing details, and finding something new to watch.

### Features

- Movies & TV shows
- Live search
- Trending content
- Personalized discovery
- Cast, seasons & episodes
- Embedded playback
- Responsive interface

## Built With

`HTML` · `CSS` · `JavaScript` · `TMDB API`

## Run

Clone the repository and open `index.html` in your browser.

```bash
git clone https://github.com/ItsMeCodyy/PrimeTV.git
```
